# Settings

::: info Community
Super Admin only.
:::

Five tabs: General, License, SSL, Backup, About.

Cleanup and Diagnostics are separate pages.

## General

Cleanup-candidate threshold (days after expiry), display timezone (default Tehran), Jalali or Gregorian calendar, and panel language.

## License

The same key-activation card. A Community installation can enter a license here.

## SSL

Certificate status, Let’s Encrypt or self-signed issue, domain change, and progress. The same tasks exist in the `sudo hm` menu.

## Backup

A **manual**, one-off snapshot. Three types: full, database only, configuration only. Generate and download, or upload an archive and restore.

Scheduled backups are in Premium **Backup Center**.

## About

Panel version, edition label, channel link, and GitHub update check.
