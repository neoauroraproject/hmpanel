# Migration

::: info Community
Super Admin only.
:::

Import from a WhalePanel database (a `.db` file). Steps:

1. Upload the backup
2. Validate the schema
3. Preview entities
4. Import panels and admins
5. Sync with the live 3x-ui panels

If inbounds or balance are wrong after import, run **Fix migration** on that admin.
