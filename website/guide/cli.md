# Command line

::: info Community
On the host: `sudo hm`
:::

Main menu:

| # | Item | Purpose |
|---|---|---|
| 1 | Panel Status | Container health |
| 2 | Panel Information | Install path and certificate |
| 3 | Update HMPanel | Update the panel |
| 4 | Create Backup | Full, database, or configuration |
| 5 | Restore Backup | Restore the database |
| 6 | Restart Services | Restart services |
| 7 | View Logs | Follow logs |
| 8 | SSL Management | Issue, renew, change domain, HTTP mode |
| 9 | System Cleanup | Host cleanup |
| 10 | Uninstall HMPanel | Remove the panel |
| 11 | Heal Panel | Emergency repair for 502 errors |

The same SSL tasks are available under **Settings → SSL**. Scheduled backups live in Premium Backup Center.
