## این ویکی چطور نوشته شده

هر صفحه شامل این‌هاست:

- **نسخه** — رایگان (همین ریپو) یا پرمیوم (دانلود بعد از فعال‌سازی لایسنس)
- **مسیر UI** و نقش (`SUPER_ADMIN` / `RESELLER`)
- **تب‌ها و اکشن‌ها** همان‌طور که در پنل دیده می‌شوند
- **endpoint**هایی که UI واقعاً صدا می‌زند (مسیر مرورگر `/api/...`)

اگر تب هست ولی API هنوز منتشر نشده، همان را می‌نویسیم. مثال: تنظیمات پرمیوم → Developer API در خود UI برچسب coming soon دارد.
