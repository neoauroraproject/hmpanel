# خط فرمان

::: info Community
روی سرور: `sudo hm`
:::

منوی اصلی:

| شماره | مورد | کار |
|---|---|---|
| 1 | Panel Status | سلامت کانتینرها |
| 2 | Panel Information | مسیر نصب و گواهی |
| 3 | Update HMPanel | به‌روزرسانی پنل |
| 4 | Create Backup | پشتیبان کامل، پایگاه‌داده یا پیکربندی |
| 5 | Restore Backup | بازیابی پایگاه‌داده |
| 6 | Restart Services | راه‌اندازی مجدد خدمات |
| 7 | View Logs | مشاهدهٔ گزارش |
| 8 | SSL Management | صدور، تمدید، تغییر دامنه، حالت HTTP |
| 9 | System Cleanup | پاکسازی میزبان |
| 10 | Uninstall HMPanel | حذف پنل |
| 11 | Heal Panel | تعمیر اضطراری خطای ۵۰۲ |

همان کارهای SSL از **تنظیمات → SSL** در رابط وب هم انجام می‌شود. پشتیبان زمان‌بندی‌شده در مرکز پشتیبان پرمیوم است.
