# ادمین‌ها

::: info Community
UI: `/admins` · فقط `SUPER_ADMIN`
:::

ساخت و ویرایش **ریسلر**.

## لیست

جستجو، صفحه‌بندی، وضعیت. ستون ترافیک باقی‌مانده/کل، تعداد کلاینت، انقضا.

## ساخت / ویرایش

فیلدهای `POST /api/admins` و `PATCH /api/admins/:id`:

- نام کاربری و رمز — تغییر نام کاربری، گروه 3x-ui را هم عوض می‌کند
- **پنل و اینباند مجاز** — حداقل یک اینباند
- سقف کلاینت (`0` = نامحدود)
- سقف ترافیک و **حالت سهمیه**: استخر سراسری یا جدا per-panel
- ترافیک نامحدود — رفراند خاموش؛ فقط کلاینت نامحدود
- روز انقضا (`0` = نامحدود)
- حسابداری: **تخصیصی** (کسر هنگام ساخت) یا **مصرفی**
- رفراند حذف / رفراند ویرایش
- فعال / غیرفعال

ادمین دارای کلاینت حذف نمی‌شود.

## بقیه اکشن‌ها

- گزارش ممیزی رفراند
- رفع مهاجرت (`fix-migration`)

ریسلر فقط `GET`/`PATCH` روی `/api/admins/:id` خودش را دارد ([تنظیمات پورتال](/fa/community/portal)).

## Endpointها

| متد | مسیر | نقش |
|---|---|---|
| `GET` | `/api/admins` | سوپر. کوئری: `page`, `limit`, `search`, `status`, `inboundId`, `panelId` |
| `POST` | `/api/admins` | سوپر |
| `GET` | `/api/admins/:id` | سوپر یا همان ادمین |
| `PATCH` | `/api/admins/:id` | سوپر یا خودش (تغییر نام فقط سوپر) |
| `DELETE` | `/api/admins/:id` | سوپر |
| `GET` | `/api/admins/audit-refunds` | سوپر |
| `POST` | `/api/admins/:id/fix-migration` | سوپر |

پرمیوم: تخصیص ماژول در [تنظیمات پرمیوم](/fa/premium/settings).
