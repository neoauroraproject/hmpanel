# عیب‌یابی

::: info Community
ویژهٔ Super Admin.
:::

نسخهٔ نصب‌شده، تصویر در حال اجرا، آخرین انتشار GitHub، نام میزبان، CPU، حافظه و دیسک را نشان می‌دهد. دسترسی به Docker و GitHub هم بررسی می‌شود.

اگر سوکت Docker به کانتینر وصل نباشد، مدیریت میزبان و ردگیری به‌روزرسانی خودکار خاموش است.

ماتریس قابلیت، تشخیص SSL و پرچم به‌روزرسانی خودکار هم همین‌جا دیده می‌شود. صفحه هر پانزده ثانیه تازه می‌شود.
