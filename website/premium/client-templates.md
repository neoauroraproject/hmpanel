# Client Templates

::: warning Premium
Enable the Client Templates module in Premium Settings.
:::

A template is a ready plan so repeated client creation is not manual. Traffic, days, IP limit, inbounds, and remark are defined once.

**With Template** appears on the Clients page. Choose a template, enter a name (or take the next name from a name pool), and create the client.

## Template fields

Name, description, inbounds, traffic in GB, expiry days, IP limit, and display order.

## Name pools

Set a prefix, separator, and start number. Each create from the template allocates the next name in sequence. If the prefix is empty, the name is typed at create time.
